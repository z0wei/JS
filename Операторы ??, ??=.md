
# JS: Операторы нулевого слияния и присваивания — `??`, `??=`

## 📌 Что это

`??` — возвращает **первое определённое** значение (не `null`/`undefined`).

`??=` — присваивает значение, **только если переменная** `null`/`undefined`.

⚠️ **«Определено»** = не `null` и не `undefined`.

---

## 🔀 Оператор `??`

**Синтаксис:**
```js
result = a ?? b;
```

**Логика:**
- Если `a` **определено** (не `null`/`undefined`) → вернуть `a`.
- Иначе → вернуть `b`.

**Эквивалент через тернарник:**
```js
result = (a !== null && a !== undefined) ? a : b;
```

**Примеры:**
```js
let user;
alert(user ?? "Аноним");        // "Аноним" (user не определён)

let user2 = "Иван";
alert(user2 ?? "Аноним");       // "Иван" (user определён)
```

**Цепочка:**
```js
let firstName = null;
let lastName = null;
let nickName = "Суперкодер";

alert(firstName ?? lastName ?? nickName ?? "Аноним");   // Суперкодер
```

---

## 🆚 `??` vs `||`

| Оператор | Что возвращает |
|----------|---------------|
| `\|\|` | первое **истинное** значение |
| `??` | первое **определённое** значение |

**Разница:**
```js
let height = 0;

alert(height || 100);   // 100 — 0 falsy, вернул 100
alert(height ?? 100);   // 0   — 0 определён, вернул 0
```

⚠️ **`||` не различает** `false`, `0`, `""` и `null`/`undefined` — для него всё это falsy.
**`??` различает** — `0` и `""` для него **определённые** значения.

**Когда использовать `??`:**
- Нужно подставить значение по умолчанию **только** для `null`/`undefined`.
- `0`, `false`, `""` — валидные значения, которые нельзя заменять.

---

## 🎯 Приоритет

`??` имеет **такой же приоритет, как `||`** (низкий — 3 в таблице MDN).

⚠️ **Нужны скобки:**
```js
let height = null;
let width = null;

// ✅ Правильно
let area = (height ?? 100) * (width ?? 50);   // 5000

// ❌ Неправильно — * выполнится первым
let area = height ?? 100 * width ?? 50;
```

---

## 🚫 Запрет с `&&` и `||`

**Нельзя использовать `??` вместе с `&&` или `||` без скобок:**

```js
let x = 1 && 2 ?? 3;      // ❌ SyntaxError
let x = (1 && 2) ?? 3;    // ✅ Работает, x = 2
```

**Зачем запрет:** чтобы избежать ошибок при переходе с `||` на `??`. Явные скобки — явное намерение.

---

## 📥 Оператор `??=`

**Присваивает значение, только если переменная `null`/`undefined`.**

**Без `??=`:**
```js
let userAge = null;

if (userAge === null || userAge === undefined) {
    userAge = 18;
}
```

**С `??=`:**
```js
let userAge = null;
userAge ??= 18;
alert(userAge);   // 18
```

**Если значение уже определено — ничего не присваивается:**
```js
let userAge = 18;

userAge ??= alert("не сработает");   // не выполнится
userAge ??= 21;                       // не выполнится
userAge ??= null;                     // не выполнится

alert(userAge);   // 18 (не изменилось)
```

## 📊 Сводная таблица

| Оператор | Что делает | Пример |
|----------|-----------|--------|
| `??` | первое определённое значение | `null ?? 5` → `5` |
| `??=` | присваивает, если `null`/`undefined` | `a ??= 5` |
| `\|\|` | первое истинное значение | `0 \|\| 5` → `5` |
| `\|\|=` | присваивает, если falsy | `a \|\|= 5` |
| `&&` | первое ложное значение | `1 && 0` → `0` |
| `&&=` | присваивает, если truthy | `a &&= 5` |

---

## 🎯 Связь с пентестом

- **`??` для дефолтов** — `config.secret ?? "default"`. Если `secret` **пустая строка** `""` — останется `""`, а не заменится (в отличие от `||`).
- **`||` может обойти проверку** — `if (user.role || "guest")`. Если `role = "0"` или `role = []` — truthy, получишь `role`, а не `"guest"`.
- **`??=` в конфигах** — `config.token ??= generateDefault()` — если токен **не задан**, сгенерируется дефолтный. Может быть уязвимостью, если дефолт слабый.
- **Разница `0` / `""` vs `null`** — в API часто приходит `0` как валидное значение. Если сервер использует `||` вместо `??`, `0` превратится в дефолт — баг.
- **Запрет с `&&`/`||`** — при ревью чужого кода обращай внимание на скобки. Если их нет — SyntaxError, если есть — читай внимательно, что именно выполнится.
