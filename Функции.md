
# JS: Функции

## 📌 Что это

**Функция** — это блок кода, который можно **вызывать много раз** по имени. Избавляет от дублирования и делает код **самодокументируемым**.

```js
function showMessage() {
    console.log('Всем привет!');
}

showMessage();   // Всем привет!
showMessage();   // Всем привет!
```

---

## 🔧 Объявление функции

```js
function имя(параметры) {
    // тело функции
}
```

- `function` — ключевое слово.
- `имя` — название (обычно глагол).
- `параметры` — через запятую, в скобках.
- `{ ... }` — тело функции.

**Вызов:** `имя()` — по имени со скобками.

---

## 🔒 Локальные переменные

Переменные, объявленные **внутри** функции, видны **только внутри**.

```js
function showMessage() {
    let message = "Привет!";   // локальная
    console.log(message);
}

showMessage();          // Привет!
console.log(message);   // ❌ ReferenceError — снаружи нет
```

---

## 🌍 Внешние (глобальные) переменные

Функция имеет **доступ** к переменным, объявленным **снаружи**, и может их **изменять**.

```js
let userName = 'Вася';

function showMessage() {
    userName = "Петя";            // ← изменили внешнюю
    console.log('Привет, ' + userName);
}

console.log(userName);   // Вася
showMessage();           // Привет, Петя
console.log(userName);   // Петя — изменилась!
```

⚠️ **Локальная перекрывает внешнюю:**

```js
let userName = 'Вася';

function showMessage() {
    let userName = "Петя";        // ← ЛОКАЛЬНАЯ
    console.log('Привет, ' + userName);   // Петя
}

showMessage();           // Привет, Петя
console.log(userName);   // Вася — внешняя не изменилась
```

**Правило:** сначала ищется **локальная** переменная, потом — внешняя.

**Совет:** минимизируй глобальные переменные. Функция должна получать данные **через параметры**, а не читать глобальные.

## 📥 Параметры и аргументы

**Параметр** — переменная в объявлении функции.
**Аргумент** — значение, передаваемое при вызове.

```js
function showMessage(from, text) {   // from, text — параметры
    console.log(from + ': ' + text);
}

showMessage('Аня', 'Привет!');       // 'Аня', 'Привет!' — аргументы
```

**Важно:** аргументы копируются в параметры. Функция **не меняет** внешние переменные через параметры.

```js
function showMessage(from, text) {
    from = '*' + from + '*';      // ← меняем ЛОКАЛЬНУЮ копию
    console.log(from + ': ' + text);
}

let from = "Аня";
showMessage(from, "Привет");      // *Аня*: Привет
console.log(from);                 // Аня — не изменилась
```

---

## 🎯 Значения по умолчанию

**Если аргумент не передан** — параметр становится `undefined`:

```js
function showMessage(from, text) {
    console.log(from + ': ' + text);
}

showMessage("Аня");   // "Аня: undefined"
```

**Значение по умолчанию через `=`:**

```js
function showMessage(from, text = "текст не добавлен") {
    console.log(from + ": " + text);
}

showMessage("Аня");           // Аня: текст не добавлен
showMessage("Аня", "Привет"); // Аня: Привет
```

**Может быть выражение:**

```js
function showMessage(from, text = anotherFunction()) {
    // anotherFunction() вызовется ТОЛЬКО если text не передан
}
```

⚠️ **Вычисляется каждый раз** при отсутствии аргумента.

## 🕰️ Старые способы (до ES6)

В старом коде можно встретить:

**Через `if`:**

```js
function showMessage(from, text) {
    if (text === undefined) {
        text = 'текст не добавлен';
    }
    console.log(from + ": " + text);
}
```

**Через `||`:**

```js
function showMessage(from, text) {
    text = text || 'текст не добавлен';
    // ⚠️ пустая строка "" тоже заменится
}
```

**Через `??` (современный):**

```js
function showCount(count) {
    console.log(count ?? "неизвестно");
}

showCount(0);      // 0        ← 0 сохраняется
showCount(null);   // неизвестно
showCount();       // неизвестно
```

**Правило:** `??` — если `0` и `""` **валидны**. `||` — если **все falsy** нужно заменить.

## 🔙 Возврат значения: `return`

Функция может **вернуть результат** в вызывающий код.

```js
function sum(a, b) {
    return a + b;
}

let result = sum(1, 2);
console.log(result);   // 3
```

**`return` немедленно прекращает функцию** — код после него **не выполняется**.

```js
function checkAge(age) {
    if (age >= 18) {
        return true;
    } else {
        return confirm('Родители разрешили?');
    }
}
```

**`return` без значения** — просто выход:

```js
function showMovie(age) {
    if (!checkAge(age)) {
        return;                 // ← выход, если false
    }
    console.log("Смотрим кино");
}
```

**Если `return` нет** — функция возвращает `undefined`:

```js
function doNothing() { }
console.log(doNothing() === undefined);   // true
```

⚠️ **Никогда не переноси строку между `return` и значением:**

```js
return
    some + long + expression;   // ❌ вернёт undefined
```

JS **автоматически** ставит `;` после `return`. **Правильно:**

```js
return (
    some + long + expression     // ✅
);
```

## 📛 Именование функций

**Имя — глагол.** Описывает, **что делает** функция.

**Общепринятые префиксы:**

| Префикс | Значение |
|---------|----------|
| `show…` | показывает |
| `get…` | возвращает значение |
| `calc…` | вычисляет |
| `create…` | создаёт |
| `check…` | проверяет, возвращает boolean |

**Примеры:**
```js
showMessage()      // показать сообщение
getAge()           // вернуть возраст
calcSum()          // вычислить сумму
createForm()       // создать форму
checkPermission()  // проверить доступ (true/false)
```

---

## 🎯 Одна функция — одно действие

Функция должна делать **то, что подразумевает имя**, и **только это**.

**Плохо:**
- `getAge` — если внутри `alert`.
- `createForm` — если меняет DOM.
- `checkPermission` — если показывает сообщение.

**Правило:** если нужно **два действия** — две функции.

---

## 🧩 Функции == Комментарии

**Маленькие функции** делают код **самодокументируемым**.

**Пример 1 — без функции:**

```js
function showPrimes(n) {
    nextPrime: for (let i = 2; i < n; i++) {
        for (let j = 2; j < i; j++) {
            if (i % j == 0) continue nextPrime;
        }
        console.log(i);
    }
}
```

**Пример 2 — с функцией:**

```js
function showPrimes(n) {
    for (let i = 2; i < n; i++) {
        if (!isPrime(i)) continue;
        console.log(i);
    }
}

function isPrime(n) {
    for (let i = 2; i < n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}
```

**Второй читается легче** — видно **что** делает `isPrime`, а не **как**.

**Правило:** можно создавать функции **даже без повторного использования** — для структуры.

## 🎯 Связь с пентестом

- **`alert()`, `prompt()`, `confirm()`** — встроенные функции.
- **`fetch()`** — функция для отправки HTTP-запросов (кража cookies).
- **`querySelector()`, `getElementById()`** — функции для работы с DOM.
- **XSS-payload'ы** — это **вызовы функций**: `alert(document.cookie)`, `fetch(...)`.
- **Обход фильтров** — можно **переопределять** функции на странице:
  ```js
  alert = function() {};   // заменить alert пустышкой
  ```
- **Prototype Pollution** — атака на **встроенные функции** и объекты.
- **`Function` как конструктор** — `new Function('return 1')` — создаёт функцию из строки. Используется для обфускации payload'ов.

**Понимание функций = понимание того, что делают payload'ы.**
