# JS: Логические операторы

## 📌 Семь операторов

`||`, `||=`, `&&`, `&&=`, `!`, `??`, `??=` (последние два — в отдельной теме).

Работают с **любыми типами**, а не только с `boolean`.

---

## 🔀 `||` (ИЛИ) — первое истинное

**Булева логика:**
```js
true  || true    // true
false || true    // true
true  || false   // true
false || false   // false
```

**С любыми типами — возвращает первое truthy-значение или последнее, если все falsy:**
```js
1 || 0                  // 1
null || 1               // 1
null || 0 || 1          // 1
undefined || null || 0  // 0 (все falsy — вернул последнее)
```

**Применение:**
```js
let firstName = "";
let lastName = "";
let nickName = "Суперкодер";

alert(firstName || lastName || nickName || "Аноним");   // Суперкодер
```

**Сокращённое вычисление** — операнды после первого truthy **не вычисляются**:
```js
true || alert("не сработает");    // alert не выполнится
false || alert("сработает");      // alert выполнится
```

---

## `||=` (логическое присваивание ИЛИ)

Присваивает `b` переменной `a`, **только если `a` falsy**.

```js
a ||= b;    // эквивалент: a || (a = b)
```

**Пример:**
```js
let johnHasCar = false;
johnHasCar ||= "У Джона нет машины!";
alert(johnHasCar);   // "У Джона нет машины!"

let manufacturer = "";
manufacturer ||= "Неизвестный производитель";
alert(manufacturer);  // "Неизвестный производитель"
```

**Аналог через `if`:**
```js
if (!johnHasCar) {
    johnHasCar = "У Джона нет машины!";
}
```

---

## 🔗 `&&` (И) — первое ложное

**Булева логика:**
```js
true  && true    // true
false && true    // false
true  && false   // false
false && false   // false
```

**С любыми типами — возвращает первое falsy-значение или последнее, если все truthy:**
```js
1 && 0                  // 0
1 && 5                  // 5
null && 5               // null
0 && "строка"           // 0
1 && 2 && null && 3     // null
1 && 2 && 3             // 3 (все truthy — вернул последнее)
```

⚠️ **Приоритет `&&` выше, чем `||`:**
```js
a && b || c && d    // = (a && b) || (c && d)
```

**Не заменяй `if` на `&&`:**
```js
// ❌ Плохо
(x > 0) && alert('x больше нуля!');

// ✅ Хорошо
if (x > 0) alert('x больше нуля!');
```

---

## `&&=` (логическое присваивание И)

Присваивает `b`, **только если `a` truthy**.

```js
a &&= b;    // эквивалент: a && (a = b)
```

**Пример:**
```js
let greeting = "Привет";
greeting &&= greeting + ", пользователь!";
alert(greeting);   // "Привет, пользователь!"
```

Используется **редко**. `||=` встречается чаще.

---

## ❗ `!` (НЕ) — инверсия

Приводит к `boolean` и **инвертирует**:
```js
!true     // false
!0        // true
!"текст"  // false
!null     // true
```

**Двойное `!!` — преобразование в boolean:**
```js
!!"непустая строка"   // true
!!null                // false
!!0                   // false
!!1                   // true
```

Аналог: `Boolean(value)`.

⚠️ **Приоритет `!` — наивысший** среди логических. Выполняется первым.

---

## 📊 Сводная таблица

| Оператор | Что возвращает | Пример |
|----------|---------------|--------|
| `\|\|` | первое truthy | `null \|\| 1` → `1` |
| `&&` | первое falsy | `1 && 0` → `0` |
| `!` | инверсию boolean | `!0` → `true` |
| `\|\|=` | присваивает, если falsy | `a \|\|= b` |
| `&&=` | присваивает, если truthy | `a &&= b` |

## 🎯 Связь с пентестом

- **`||` для дефолтных значений** — `if (user.role || "guest")`. Если `role = ""` — получит `"guest"`.
- **`&&` в проверках** — `if (user && user.isAdmin)`. Если `user = 0` — проверка не пройдёт, но если `user = "0"` — **пройдёт** (truthy).
- **`!!` для преобразования** — используется для явного приведения: `!!token` → true/false.
- **Сокращённое вычисление** — `isAdmin && deleteUser()` — если `isAdmin` falsy, `deleteUser` не вызовется.
- **Обход авторизации** — если проверка `if (user && user.role === "admin")`, но `user.role` можно установить в `"admin"` через другой вектор — доступ получен.
- **`||=` в уязвимостях** — `config.secret ||= "default"` — если `secret` пустой, подставится дефолт, что может быть использовано.
