# JS: Условное ветвление — if, ?

## 📌 Что это

Инструкция `if` и тернарный оператор `?` позволяют **выполнять разный код** в зависимости от условия.

---

## 🔀 Инструкция `if`

```js
if (условие) {
    // выполнится, если условие == true
}
```

**Пример:**
```js
let year = prompt('В каком году вышел ECMAScript-2015?', '');

if (year == 2015) {
    alert('Вы правы!');
}
```

⚠️ **Всегда используй `{}`**, даже если одна строка — улучшает читаемость.

---

## 🔢 Преобразование к логическому типу

Условие в `if (...)` **автоматически** преобразуется к `boolean`.

**Falsy (ложные) — становятся `false`:**
- `0`
- `""` (пустая строка)
- `null`
- `undefined`
- `NaN`

**Truthy (правдивые) — всё остальное:**
- Любое число, кроме `0` (включая `-1`, `0.5`)
- Непустая строка (включая `"0"` и `" "`)
- Массивы, объекты (даже пустые)

**Примеры:**
```js
if (0) { ... }          // никогда не выполнится
if (1) { ... }          // выполнится всегда
if ("0") { ... }        // выполнится! (непустая строка — truthy)
if ([]) { ... }         // выполнится! (пустой массив — truthy)
```

**Можно сохранить условие в переменную:**
```js
let condition = (year == 2015);   // true или false
if (condition) { ... }
```

---

## 🚪 Блок `else`

Выполняется, когда условие **ложно**.

```js
let year = prompt('Год ECMAScript-2015?', '');

if (year == 2015) {
    alert('Да вы знаток!');
} else {
    alert('А вот и неправильно!');
}
```

---

## 🔗 Несколько условий: `else if`

```js
let year = prompt('Год ECMAScript-2015?', '');

if (year < 2015) {
    alert('Слишком рано...');
} else if (year > 2015) {
    alert('Поздновато');
} else {
    alert('Верно!');
}
```

**Логика:**
1. Проверяется `year < 2015`.
2. Если `false` — проверяется `year > 2015`.
3. Если оба `false` — выполняется `else`.

⚠️ **`else` необязателен.** `else if` может быть много.

---

## ❓ Тернарный оператор `? :`

**Три аргумента** — единственный такой оператор в JS.

**Синтаксис:**
```js
let result = условие ? значение1 : значение2;
```

**Как читается:**
- Если `условие` → `true` — вернуть `значение1`.
- Если `false` — вернуть `значение2`.

**Пример:**
```js
let age = prompt('Сколько вам лет?', '');

let accessAllowed = (age > 18) ? true : false;
```

**То же самое через `if`:**
```js
let accessAllowed;
if (age > 18) {
    accessAllowed = true;
} else {
    accessAllowed = false;
}
```

⚠️ **Скобки не обязательны**, но улучшают читаемость. Приоритет `?` ниже, чем у `>`.

⚠️ **Упрощение:** если условие само возвращает `true`/`false`, тернарник не нужен:
```js
let accessAllowed = age > 18;   // то же самое
```

---

## 🔗 Несколько операторов `?`

Можно строить цепочки для нескольких условий:

```js
let age = prompt('Возраст?', 18);

let message = (age < 3) ? 'Здравствуй, малыш!' :
              (age < 18) ? 'Привет!' :
              (age < 100) ? 'Здравствуйте!' :
              'Какой необычный возраст!';

alert(message);
```

**Читается как:**
1. `age < 3`? → `'Здравствуй, малыш!'`
2. Иначе `age < 18`? → `'Привет!'`
3. Иначе `age < 100`? → `'Здравствуйте!'`
4. Иначе → `'Какой необычный возраст!'`

**То же через `if`:**
```js
if (age < 3) {
    message = 'Здравствуй, малыш!';
} else if (age < 18) {
    message = 'Привет!';
} else if (age < 100) {
    message = 'Здравствуйте!';
} else {
    message = 'Какой необычный возраст!';
}
```

---

## ⚠️ Нетрадиционное использование `?`

`?` **можно** использовать вместо `if`, но **не рекомендуется**:

```js
// ❌ Плохо — тяжело читать
(company == 'Netscape') ?
    alert('Верно!') : alert('Неправильно.');

// ✅ Хорошо
if (company == 'Netscape') {
    alert('Верно!');
} else {
    alert('Неправильно.');
}
```

**Правило:** `?` — для **возврата значения**. `if` — для **выполнения кода**.

---

## 🎯 Связь с пентестом

- **Проверка `if (user)`** — truthy-значения. Если `user = "0"` или `user = " "`, проверка **пройдёт**, хотя выглядит как «нет».
- **`if (role == "admin")`** — если забыли `===`, `role = 0` может пройти.
- **Falsy-значения** — `0`, `""`, `null`, `undefined`, `NaN`. Если проверка `if (token)` пропускает пустой `""`, будет баг.
- **Тернарник в payload'ах** — `?` часто используется в обфускации JS.
- **Логика `else if`** — сервер может проверять роль в определённом порядке. Если найдёшь, где порядок неверный — обойдёшь авторизацию.
- **Пример уязвимости:** `if (user.role == "admin")` — если `role` придёт как `["admin"]` (массив), проверка может сработать неожиданно.
