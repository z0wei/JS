# JS переменные
чтобы создать переменную используется let например
let A1234;
чтобы положить в переменную данные можно написать 
let A1234; (создаем переменную)
A1234 = 'hello!'; (положим туда данные)
alert(A1234); (также мы можем вывести данные из переменной командой alert)
также может в старом коде использоваться вместо let команда var
повторное создание переменной вызовет ОШИБКУ например
let A1234 = 'hay';
let A1234 = 'hey!';
alert(A1234); (произойдет ошибка поэтому не нужно вызывать переменную два раза)
правильно использование переменной два раза 
let A1234 = 'hey'; (создаем переменную)
A1234 = 'hello'; (заменяем значение в переменной на другую старая при этом удаляется)
alert(A1234); (выводим переменную с новым значением)
## существуют функциональные языки программирования, такие как Scala или Erlang, которые запрещают изменять значение переменной!
можно скопировать данные из одной переменной в другую например
let world = 10;
let world2;
world = world2;
alert(world2); (в выводе будет число 10)
Имена переменных
### В JavaScript есть два ограничения, касающиеся имён переменных:
### Имя переменной должно содержать только буквы, цифры или символы $ и _.
### Первый символ не должен быть цифрой.
let $ = 123;
let _ = 1;
alert($ + _); (так складываются значения переменных получиться 124) 
## нельзя использовать в качестве имён переменных, потому что они используются самим языком: let, class, return и function зарезервированы.
так же может let может не использоваться при определенных настройках проекта 
xxx = 5; (записывается в переменную значение если до этого переменной не было она создаться)
alert(xxx); (Вывод 5)
## чтобы создать неизменяемую переменную взаместо let используется const например 
const COLOR_RED = "#F00";
const COLOR_GREEN = "#0F0";
const COLOR_BLUE = "#00F";
const COLOR_ORANGE = "#FF7F00";
// ...когда нам нужно выбрать цвет
let color = COLOR_ORANGE;
alert(color); // #FF7F00
### при попытке изменить переменную const будет ОШИБКА!
## Итого
#### Мы можем объявить переменные для хранения данных с помощью ключевых слов var, let или const.
#### let – это современный способ объявления.
#### var – это устаревший способ объявления. Обычно мы вообще не используем его, но мы рассмотрим тонкие отличия от let в главе Устаревшее ключевое слово "var" на случай, если это всё-таки вам понадобится.
#### const – похоже на let, но значение переменной не может изменяться.
#### Переменные должны быть названы таким образом, чтобы мы могли легко понять, что у них внутри.
