# Типы данных
есть разные типы данных их всего 8
1) number //числа и числа с плавающей точкой также мы можем выполнять / * + - например
   let numder = 3;
   tet number1 = 3;
   alert (number + number); // Вывод: 6
2) Infinity //представляет собой математическую бесконечность например
   let infinity = ( 1 / 0 ); //таким способом мы получим бесконечность
   alert(infinity); //так же мы можем вывести бесконечность без создания переменной с let
3) NaN //ошибка при выполнения математических вычислений или использования NaN в вычислениях например
   alert( adc / 13 ); // Вывод: NaN
   alert( NaN / 13); // тоже Вывод: Nan
   ### НО!
   alert( NaN ** 0 ); // Вывод: 1
4) BigInt // создан для работы с числами произвольной длины т.к number есть ограничение по длине
   alert(31241324325424231421342141234124123412432n); //для обьявленния используется n в конце числа
   ### НО!
   В данный момент BigInt поддерживается только в браузерах Firefox, Chrome, Edge и Safari, но не поддерживается в IE.
5) string //строка в кавычках "" '' `` например
   alert("hello");
   alert('hello');
   alert(`hello ${6 / 3}`); // с помощью `` мы можем вставить в string любое значение цифру символ и т.д Вывод: hello 2
   ### НО!
   если будут не развернутые кавычки трюк с ${123} не сработает!
6) boolean может хранить только true или false
   let yes = true;
   let no = false;
   или
   let true_or_false = 5 > 1;
   alert(true_or_false); // Вывод: true
7) null //просто пустота или неизвестное
   let age = null; 
8) undefined //используется для проверки наличия значений
   let age;
   alert(age); // Вывод: undefined
   ## Итого
В JavaScript есть 8 основных типов данных.
Семь из них называют «примитивными» типами данных:
number для любых чисел: целочисленных или чисел с плавающей точкой; целочисленные значения ограничены диапазоном ±(253-1).
bigint для целых чисел произвольной длины.
string для строк. Строка может содержать ноль или больше символов, нет отдельного символьного типа.
boolean для true/false.
null для неизвестных значений – отдельный тип, имеющий одно значение null.
undefined для неприсвоенных значений – отдельный тип, имеющий одно значение undefined.
symbol для уникальных идентификаторов.
И один не является «примитивным» и стоит особняком:
object для более сложных структур данных.
Оператор typeof позволяет нам увидеть, какой тип данных сохранён в переменной.
Имеет две формы: typeof x или typeof(x).
Возвращает строку с именем типа. Например, "string".
Для null возвращается "object" – это ошибка в языке, на самом деле это не объект.
