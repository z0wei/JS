
# JS: Преобразование типов

## 📌 Что это

JavaScript **автоматически** преобразует типы в зависимости от контекста. Это называется **неявное преобразование** (implicit coercion). Также можно преобразовать **явно** через функции.

**Три основных преобразования:** строковое, численное, логическое.

---

## 📝 1. Строковое преобразование

**Когда:** когда нужно вывести значение или склеить со строкой.

**Как вызвать явно:** `String(value)`

```js
String(123);        // "123"
String(true);       // "true"
String(null);       // "null"
String(undefined);  // "undefined"
String([1, 2, 3]);  // "1,2,3"
```

**Неявное:**
```js
'Возраст: ' + 16;   // "Возраст: 16"
```

---

## 🔢 2. Численное преобразование

**Когда:** в математических операциях (`-`, `*`, `/`, `%`).

**Как вызвать явно:** `Number(value)`

**Правила:**

| Значение | Становится |
|----------|-----------|
| `undefined` | `NaN` |
| `null` | `0` |
| `true` | `1` |
| `false` | `0` |
| `"123"` | `123` |
| `"  42  "` | `42` (пробелы обрезаются) |
| `""` | `0` |
| `"abc"` | `NaN` |

**Примеры:**
```js
Number('123');       // 123
Number('  42  ');    // 42
Number('');          // 0
Number('abc');       // NaN
Number(true);        // 1
Number(null);        // 0
Number(undefined);   // NaN
```

**Неявное:**
```js
'10' - 5;            // 5 (строка → число)
'10' + 5;            // "105" (число → строка!)
```

⚠️ **Опасность:** `+` со строкой **склеивает**, а не складывает.

---

## ✅ 3. Логическое преобразование

**Когда:** в логических операциях (`if`, `&&`, `||`, `!`).

**Как вызвать явно:** `Boolean(value)`

**Правила:**

| Значение | Становится |
|----------|-----------|
| `0`, `null`, `undefined`, `NaN`, `""` | `false` |
| **Всё остальное** | `true` |

**Примеры:**
```js
Boolean(0);          // false
Boolean('');         // false
Boolean('0');        // true  ⚠️ строка "0" — truthy
Boolean(' ');        // true  ⚠️ строка из пробелов — truthy
Boolean(null);       // false
Boolean(undefined);  // false
Boolean(NaN);        // false
Boolean([]);         // true  ⚠️ пустой массив — truthy
Boolean({});         // true  ⚠️ пустой объект — truthy
```

**Неявное:**
```js
if ('text') { /* сработает — строка truthy */ }
if (0) { /* не сработает */ }
```

---

## ⚠️ Частые ошибки

1. **`undefined` при численном преобразовании → `NaN`, а не `0`.**
   ```js
   Number(undefined);  // NaN
   ```

2. **`"0"` и `" "` при логическом преобразовании → `true`.**
   ```js
   Boolean('0');       // true
   Boolean(' ');       // true
   ```

3. **`+` со строкой — это конкатенация, а не сложение.**
   ```js
   '5' + 3;            // "53", не 8
   '5' - 3;            // 2
   ```

4. **`==` делает преобразование типов, `===` — нет.**
   ```js
   0 == '';            // true  (оба → false → 0)
   0 === '';           // false (разные типы)
   ```

---

## 🎯 Связь с пентестом

- **`'5' + 3` → `"53"`** — важно при построении payload'ов, чтобы не сломать строку.
- **Неявное преобразование в `if`** — используется в логике авторизации. Если проверка `if (user.role)` — то `role = "0"` пройдёт как **truthy**, хотя выглядит как «нет».
- **`==` vs `===`** — классическая причина багов. Например, `if (token == 0)` может пропустить `token = ""`.
- **`Number()` в инъекциях** — если сервер ожидает число, а получает `NaN`, может упасть.
- **XSS через приведение типов** — иногда payload проходит проверку как строка, но выполняется как код.
