
# JS: DOM-дерево

## 📌 Что это

**DOM** (Document Object Model) — представление HTML-документа в виде **дерева объектов**. Каждый HTML-тег — это **объект**, доступный из JavaScript.

**Ключевая идея:** всё, что есть в HTML, есть и в DOM. И наоборот.

---

## 🌳 Структура дерева

**HTML:**
```html
<!DOCTYPE HTML>
<html>
<head>
  <title>О лосях</title>
</head>
<body>
  Правда о лосях.
</body>
</html>
```

**DOM-дерево:**
```
HTML
├─ HEAD
│  └─ TITLE
│     └─ #text "О лосях"
└─ BODY
   └─ #text "Правда о лосях."
```

**Как читать:**
- `<html>` — **корневой узел**.
- `<head>`, `<body>` — **дети** `HTML`.
- `<title>` — **ребёнок** `HEAD`.
- `"О лосях"` — **текстовый узел** (`#text`).

---

## 🧩 Типы узлов

| Тип | Обозначение | Что это |
|-----|-------------|---------|
| **document** | — | «Входная точка» в DOM |
| **Узел-элемент** | `<tag>` | HTML-тег |
| **Текстовый узел** | `#text` | Текст внутри тега |
| **Комментарий** | `#comment` | `<!-- ... -->` |

⚠️ **Всего 12 типов**, но на практике — эти **4**.

---

## 📦 Что такое узел

**Каждый узел — это объект.**

- `<body>` → `document.body`
- `<html>` → `document.documentElement`
- `document` → сам документ

**Пример изменения через JS:**
```js
document.body.style.background = 'red';   // фон красный

setTimeout(() => document.body.style.background = '', 3000);   // через 3 сек — вернуть
```

---

## 📝 Текстовые узлы (`#text`)

**Текст внутри тега — это отдельный узел.**

```html
<title>О лосях</title>
```
→ В DOM **два** узла:
- `<title>` — элемент.
- `#text "О лосях"` — его ребёнок.

**Текстовый узел:**
- Содержит **только строку**.
- **Не может иметь детей.**
- Всегда на **самом нижнем уровне**.

---

## 🅰️ Пробелы — тоже узлы

**Перевод строки (`\n`) и пробел (` `) — полноправные символы.**

```html
<head>
  <title>...</title>
</head>
```

**Между `<head>` и `<title>` — пробелы и переносы** → в DOM появляется **текстовый узел `#text`** с этими пробелами.

**Исключения:**
1. Пробелы **перед `<head>`** игнорируются (историческое правило).
2. Всё **после `</body>`** браузер **переносит в конец `<body>`**.

**Пример без пробелов:**
```html
<html><head><title>О лосях</title></head><body>Правда о лосях.</body></html>
```
→ DOM **чище**, без лишних `#text`.

⚠️ **В DevTools** пробельные узлы **скрыты** для экономии места.

## 🔧 Автоисправление браузером

Браузер **сам** исправляет невалидный HTML.

### Пример 1: нет `<html>` и `<body>`

```html
Привет
```

**DOM:**
```
HTML
├─ HEAD
└─ BODY
   └─ #text "Привет"
```

Браузер **сам создал** `HTML`, `HEAD`, `BODY`.

### Пример 2: незакрытые теги

```html
<p>Привет
<li>Мама
<li>и
<li>Папа
```

**DOM:**
```
BODY
├─ P
│  └─ #text "Привет"
├─ LI
│  └─ #text "Мама"
├─ LI
│  └─ #text "и"
└─ LI
   └─ #text "Папа"
```

Браузер **сам закрыл** теги.

### Пример 3: таблицы всегда с `<tbody>`

```html
<table id="table"><tr><td>1</td></tr></table>
```

**DOM:**
```
TABLE
└─ TBODY       ← браузер добавил сам
   └─ TR
      └─ TD
         └─ #text "1"
```

⚠️ **Важно:** работая с таблицами, помни — `<tbody>` **всегда есть** в DOM, даже если его нет в HTML.

## 💬 Комментарии в DOM

```html
<!-- комментарий -->
```

→ узел **`#comment`** в DOM.

**Зачем комментарий в DOM?** Он не влияет на отображение, но **доступен из JS**.

⚠️ **Правило:** всё, что есть в HTML — есть в DOM. Даже комментарии, `<!DOCTYPE>`, и сам `document`.

---

## 🛠️ DevTools (инструменты разработчика)

**Открыть:** `F12` → вкладка **Elements**.

**Что показывает:**
- DOM-дерево в **упрощённом** виде.
- Текстовые узлы — **просто текст**.
- Пробельные узлы — **скрыты**.

**Полезные фичи:**

| Действие | Что делает |
|----------|-----------|
| **ПКМ → Inspect** на элементе | Находит элемент в DOM |
| **Кнопка «выбрать элемент»** (вверху панели) | Тыкаешь по странице — элемент подсвечивается |
| **Styles** (справа) | CSS правила для элемента |
| **Computed** | Итоговые CSS-свойства |
| **Event Listeners** | Обработчики событий |

---

## 🔗 Связь Elements ↔ Console

**Из Elements в Console:**

1. Кликни на элемент во вкладке **Elements**.
2. Нажми **Esc** — откроется **Console** внизу.
3. Последний выбранный элемент → **`$0`**.
4. Предыдущий → **`$1`** и т.д.

**Пример:**
```js
$0.style.background = 'red';   // выделит выбранный элемент красным
```

**Из Console в Elements:**

```js
inspect(node);   // покажет узел во вкладке Elements
```

**Просто вывод узла:**
```js
console.log(document.body);   // исследуй «на месте» в консоли
```

## 🎯 Связь с пентестом

- **DOM — цель XSS.** Payload попадает в DOM и выполняется браузером.
- **`document.body`, `document.cookie`** — свойства DOM-объектов.
- **`document.querySelector(...)`** — метод поиска элементов в DOM.
- **`innerHTML`** — **свойство DOM-элемента**, через которое вставляется HTML. Именно там — XSS.
- **Текстовые узлы** — payload может оказаться **в тексте** между тегами. Тогда `<script>` сработает **напрямую**.
- **Атрибуты тегов** (`value="..."`, `href="..."`) — payload в **атрибуте**. Нужно **закрыть кавычку** и тег.
- **DOM-based XSS** — уязвимость **на клиенте**, без сервера. `location.hash` → `innerHTML`.
- **Shadow DOM** — изолированный DOM (веб-компоненты). Может **скрывать** уязвимости.
- **Автоисправление браузера** — важно для **обхода фильтров**: то, что ты пишешь в payload, браузер может **изменить** при парсинге.
- **`<tbody>` добавляется автоматически** — иногда payload в `<table>` вставляется в **неожиданное место**.

**Правило:** понимание DOM — обязательно для **DOM-based XSS** и анализа **клиентской части** сайта.
