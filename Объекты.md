
# JS: Объекты

## 📌 Что это

**Объект** — коллекция пар «ключ: значение». Используется для хранения сложных сущностей.

```js
let user = {
    name: "John",     // ключ: "name", значение: "John"
    age: 30           // ключ: "age", значение: 30
};
```

**Аналогия:** ящик с подписанными папками. По ключу легко найти, добавить или удалить значение.

---

## 🔧 Создание объекта

**Литерал (обычный способ):**
```js
let user = {};
```

**Конструктор (устаревший):**
```js
let user = new Object();
```

---

## 🔑 Доступ к свойствам

### 1. Через точку — для простых имён

```js
user.name           // "John"
user.age            // 30
```

⚠️ Не работает для имён с пробелами и спецсимволами.

### 2. Через квадратные скобки — для сложных имён

```js
user["likes birds"]     // работает, если ключ с пробелом
```

**Можно использовать переменную:**
```js
let key = "name";
user[key]            // "John"
```

⚠️ `user.key` — вернёт `undefined`, потому что ищет буквально свойство `"key"`.

**Правило:**
- Простые имена → **точка**.
- Имена из переменных или сложные → **скобки**.

---

## ✏️ Добавление, изменение, удаление

```js
user.isAdmin = true;         // добавить/изменить
user.name = "Pete";          // изменить
delete user.age;             // удалить
```

---

## 🔒 `const` не защищает содержимое

```js
const user = { name: "John" };

user.name = "Pete";          // ✅ Работает
user = { name: "Pete" };     // ❌ Ошибка — нельзя переприсвоить
```

`const` защищает **переменную** (ссылку), а не **содержимое**.

---

## 🧮 Вычисляемые свойства

Имя свойства можно взять из переменной через `[...]`:

```js
let fruit = prompt("Какой фрукт?", "apple");

let bag = {
    [fruit]: 5           // имя свойства = значение переменной fruit
};

alert(bag.apple);        // 5, если fruit = "apple"
```

Можно использовать выражения:
```js
[fruit + 'Computers']: 5     // bag.appleComputers = 5
```

---

## ✂️ Сокращённые свойства

Если имя переменной совпадает с ключом:

```js
function makeUser(name, age) {
    return {
        name,        // то же самое, что name: name
        age          // то же самое, что age: age
    };
}
```

---

## ⚠️ Ограничения на имена

**Для объектов НЕТ ограничений** — можно использовать зарезервированные слова:

```js
let obj = {
    for: 1,
    let: 2,
    return: 3
};
```

**Числовые ключи** автоматически преобразуются в строки:
```js
let obj = { 0: "Тест" };

obj["0"]     // "Тест"
obj[0]       // "Тест" — то же самое
```

---

## 🔍 Проверка существования свойства

### Способ 1 — сравнение с `undefined`

```js
let user = {};

user.noSuchProperty === undefined    // true — свойства нет
```

### Способ 2 — оператор `in`

```js
"age" in user        // true — если свойство есть
"blabla" in user     // false
```

⚠️ **Разница:** если свойство существует, но равно `undefined`:
```js
let obj = { test: undefined };

obj.test === undefined    // true — «не существует»?
"test" in obj             // true — СУЩЕСТВУЕТ!
```

**Правило:** для надёжной проверки — **`in`**.

---

## 🔁 Цикл `for...in`

Перебирает **все ключи** объекта:

```js
let user = { name: "John", age: 30, isAdmin: true };

for (let key in user) {
    console.log(key);          // name, age, isAdmin
    console.log(user[key]);    // John, 30, true
}
```

⚠️ **Цикл `for...in` отличается от `for(;;)`.**

---

## 📊 Порядок свойств

**Целочисленные ключи** — сортируются по **возрастанию**:
```js
let codes = { "49": "Германия", "1": "США", "41": "Швейцария" };

for (let code in codes) console.log(code);   // 1, 41, 49
```

**Остальные** — в порядке **создания**:
```js
let user = { name: "John", surname: "Smith" };
user.age = 25;

for (let prop in user) console.log(prop);    // name, surname, age
```

**Если важен порядок** для числовых ключей — добавь `+`:
```js
let codes = { "+49": "Германия", "+1": "США" };
// теперь в порядке создания
```

## 🎯 Связь с пентестом

- **`document` — это объект.** `document.cookie` — свойство. `document.querySelector(...)` — метод.
- **`window` — объект.** `window.location` — свойство.
- **XSS-payload'ы работают с объектами:**
  ```js
  document.cookie
  window.location.href
  document.querySelector('input').value
  ```
- **`__proto__` — опасное свойство.** Используется в Prototype Pollution:
  ```js
  obj.__proto__ = ...     // атака на прототип
  ```
- **`in` и `hasOwnProperty`** — помогают понять, есть ли свойство у объекта.
- **`for...in`** — используется для обхода объектов в чужом коде, помогает найти интересные свойства.
- **Вычисляемые свойства `[key]`** — позволяют обращаться к свойствам по имени из переменной, что часто в эксплойтах:
  ```js
  let sink = document["cookie"];    // то же, что document.cookie
  ```
